# Suivi commercial des demandes

Ce modèle se remplit à la main à partir de l’e-mail reçu sur contact@coconsult.fr. Cette version n’ajoute ni base de données, ni back-office, ni CRM.

Chaque ligne correspond à une demande envoyée volontairement depuis le formulaire. La source déclarée est celle choisie par le visiteur. Le parcours indique seulement si le formulaire a été ouvert directement ou après le guide commercial.
